## PART 2 — REJECTED

- **R1 — paperclip-reality: probe `filter` latency/caching in s0.** Mooted: A20 deletes the s2 filter pass; deterministic screening + map-eligible covers it. (If the back-pocket filter is ever used for topic A, freeze claim wording then — one sentence, not an s0 item.)
- **R2 — stats-rigor: 50/50 discovery/validation paper split for the agent loop.** At ~30–50 papers the split halves both the discovery signal and the validation power and burns integration time; the critic's own fallback (rename + say the caveat) buys ~90% of the honesty for ~2% of the cost. Accepted as the rename in A11.
- **R3 — stats-rigor: Miller–Madow correction for the G3 gate.** Over-spec; the bootstrap interval in A12 already absorbs the small-sample bias for a binary gate decision. Adding a bias-corrected estimator to a go/no-go check is precision theater at 8 PM.
- **R4 — demo-narrative: pre-authorize C→C+B merge as "the sole permitted overnight topic change."** Rejected as an *overnight* option specifically — it contradicts B5 (overnight is additive-only) and B6 already places the merge as a G2-time escalation rung, which is when a topic change is still survivable.
- **R5 — scope-yagni: cut `effect_size` entirely.** Keep it as one nullable raw string (the stretch numeric MA and the recovery framing may want it; a single nullable field costs nothing at extraction). `effect_size_type` stays cut per A15.
- **R6 — time-realism: shrink probes to 5 papers.** Rejected — collides with stats-rigor's demonstration that probe entropy is already noise-dominated at n≈10; 5-paper entropy is a coin flip. The time is recovered by triaging fewer topics (A16), not thinner ones.
- **R7 — failure-modes: funnel-plot glance for publication bias.** The caveat card + sentence (A19a) is the accepted mitigation; a funnel plot needs commensurate effect sizes, which are a cut stretch goal. Listed in the doc as a 15-min stretch only.
- **R8 — paperclip-reality: promote map parallelism investigation.** The design already commits to sequential windows pending s0 latency measurement; nothing to change.

## PART 3 — CONFLICTS ADJUDICATED

- **C1. scope-yagni ("kill content-addressed caching") vs data-engineering ("cfghash must key the cache or versions mix").** Both are right about different halves: hash-keyed cache-*hit* logic is a 2 AM phantom-cache sink, AND version mixing after the guaranteed G3 prompt revision silently inverts direction labels. **Resolution (B4):** no cache-hit logic at all — fixed paths + `--force` + human decides re-runs — but cfghash lives in `run.json` and raw filenames, and s4 hard-asserts single-version tuples. DE's safety property is preserved without Y's failure mode.
- **C2. scope-yagni ("diet the schema, cut author_conclusion_agrees") vs data-engineering ("push dose normalization INTO the schema") vs failure-modes ("author_conclusion_agrees is circular — redesign it").** **Resolution (A15/A19):** diet wins on ballast fields; DE wins on dose (its fields are load-bearing for the headline result and replace an unowned parser); the conclusion-bias field is cut *and* its job is done better by the mechanical section-flag on `evidence_lines` — failure-modes' actual complaint was circularity, which the flag eliminates.
- **C3. time-realism ("5-paper probes to fit the 90-min budget") vs stats-rigor ("probe entropy at n≈10–25 is already bias + noise").** **Resolution (A16 + R6):** cut topics, not probe depth; gate on the bootstrap interval, not the point estimate.
- **C4. time-realism ("triage C, C+B, A") vs scope-yagni ("C+B probe is a critical-path tax; count-only") vs D10's tie-break toward C.** **Resolution (A16):** probes for C and A; C+B count-only; merge demoted to escalation rung. The tie-break toward C may fire only after the dose-regime grep count clears min-support on both sides (failure-modes' condition) — this constrains D10 rather than deleting it.
- **C5. Design D9 ("dashboard only after s5 produces a real pattern") vs four lenses demanding a Saturday skeleton.** **Resolution (B1):** the lenses win unanimously; §41-10 warns against polishing before a result, not against plumbing. The design misread its own source.
- **C6. scope-yagni ("200 permutations → 100") vs stats-rigor's Westfall–Young requirement.** No conflict in substance: max-T needs the permutations that already run; at 100 perms the min resolvable family-wise p is ~0.01, ample for a demo claim. Both accepted (A10 + A14).
- **C7. Design cut-order ("static Plotly HTML fallback") vs never-cut list ("evidence display").** The design conflicts with *itself*; scope-yagni and demo-narrative both caught it. Resolution: B8.
