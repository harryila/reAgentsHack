Four structural defects: (1) the whole Saturday chain hangs on an auth event with unknown ETA and an unarmed fallback (the Claude-API path needs a second credential nobody has yet); (2) no milestone ever allocates time to WRITE the analysis and dashboard code — the fixture path that fixes this exists only as an auth-delay contingency; (3) the statistical controls that protect the headline claim run after the 10:30 PM decision they are supposed to gate, and the 'agentic' remap requires a human approval scheduled for when the only human is asleep; (4) dashboard assembly, audit finalization, rehearsal, and an unknown-format submission artifact are all compressed into a 105-minute Sunday window with 45 minutes of terminal slack. None of this requires descoping the idea. The surgery is mostly resequencing: make fixture-driven s4–s7 + dashboard skeleton the unconditional main thread starting now; resolve the Anthropic key and the submission format today; run permutation/bootstrap at the M4 gate; execute the remap approval before sleep and make the overnight run additive-only behind a checkpointed runner; record a backup demo video Saturday midnight; freeze at 9:45 AM, not 10:00.
